# Legal And Scope Notes

This project should stay focused on interoperability, learning, modding research, preservation, and clean-room documentation.

## Allowed Project Artifacts

- File hashes and metadata.
- Function names, addresses, call relationships, and short behavioral summaries.
- Manually written struct layouts and file-format specs based on observation.
- Scripts that inventory the local install or parse synthetic/local user-provided files.
- Clean-room code that implements documented behavior without copying proprietary source.

## Avoid

- Publishing copied assets, binaries, or IDA databases.
- Publishing substantial decompiler pseudocode or reconstructed proprietary source.
- Removing license checks, bypassing Steam, or enabling unauthorized online access.
- Shipping patches that facilitate cheating on public servers.

## Working Rule

Keep this repository as the notebook and tooling layer. Keep proprietary inputs in the Steam install and analyzer databases outside Git.
